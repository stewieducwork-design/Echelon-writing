One-time setup

Connect your free cloud

This lets students submit remotely and lands every script on your desk. About 10 minutes, done once.

Create a free Firebase project

Go to console.firebase.google.com, click Add project, give it any name, and finish. You can skip Google Analytics.

Turn on Firestore & Authentication

In the left menu: Build → Firestore Database → Create database (start in production mode, any location). Then Build → Authentication → Get started → Email/Password → Enable. Add one user under the Users tab — that is your teacher login.

Copy your web config

Project settings (gear icon) → scroll to Your apps → click the web icon </> → register the app → copy the firebaseConfig object. Paste it into this file where it says FIREBASE_CONFIG near the top of the script, then re-upload to GitHub.

Paste the security rules

Firestore Database → Rules tab → replace everything with the block below → Publish. Change the email to your teacher login.

Prefer to skip all this? You can use MarQ in on-device demo mode — everything works, but scripts only live on the machine they were written on. Good for trying it out; not for remote classes.
